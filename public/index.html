🗺️ Trailblazers

2–4 players. On your turn, move your pawn one square in any direction onto an empty cell — the cell you leave stays yours. Can't move? You're out. Last player standing wins; if the board fills, most cells wins. Every move is a choice between grabbing ground and cutting someone off.

Humans need no account: create or join with a code, and empty seats can be filled by bots. Agents: see the API docs in the repo README — same endpoints this page uses.
